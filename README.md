# دعوة زفاف عبدالله وخلود 🤍

موقع دعوة زفاف — HTML/CSS/JS بس، من غير build ولا مكتبات، يشتغل على GitHub Pages على طول.

**التفاصيل:** السبت ١٠ أكتوبر ٢٠٢٦ — من ٣ عصرًا حتى ٧ مساءً — قاعة سندريلا، قصر الأميرات، حديقة العاشر من رمضان، شارع الطيران، الحي السابع، مدينة نصر، القاهرة.

## اللي في الموقع

- الآية الكريمة في أول الصفحة
- بطاقة الدعوة بزخارف ركنية وأسماء بخط الرقعة (Aref Ruqaa)
- رسمة العريس والعروسة (SVG ملوّن — بدلة كحلي وفستان بطرحة وبوكيه)
- عد تنازلي حيّ لحد الفرح
- كروت التاريخ / الموعد / المكان
- خرائط جوجل + Bing + **كود QR** لمكان القاعة
- زرار "أضف الموعد للتقويم" (`.ics` بتنبيه قبلها بيوم)، مشاركة واتساب، نسخ الرابط

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | كل المحتوى + الرسمة والزخارف والـ QR (كلها SVG جوّه الملف) |
| `styles.css` | التصميم والألوان |
| `script.js` | العد التنازلي، ملف التقويم، المشاركة |
| `images/couple.jpg` | صورتكم (اختياري — انظر تحت) |
| `tools/` | سكربتات بايثون اللي ولّدت الرسمة والزخرفة والـ QR (مش مطلوبة عشان الموقع يشتغل) |

## تحطّ صورتكم الحقيقية إزاي

حطّ الصورة باسم **`images/couple.jpg`** بالظبط. الموقع هيلاقيها لوحده ويحطها مكان الرسمة،
ولو مش موجودة يرجّع الرسمة تلقائيًا. يُفضّل صورة عرضية بنسبة قريبة من ‎580×512‎.

## الرفع على GitHub Pages

```bash
cd wedding-abdallah-kholoud
git remote add origin https://github.com/<اسم-حسابك>/<اسم-الريبو>.git
git push -u origin main
```

بعدين من صفحة الريبو: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**

والرابط هيبقى: `https://<اسم-حسابك>.github.io/<اسم-الريبو>/`

## تعديلات سريعة

- **الأسماء / التاريخ / المكان:** نص عادي جوّه `index.html`.
- **موعد العد التنازلي:** أول سطرين في `script.js` — `new Date(2026, 9, 10, 15, 0, 0)`
  (الشهر بيبدأ من صفر، يعني `9` = أكتوبر).
- **الألوان:** أول `styles.css` جوّه `:root`.
- **كود الـ QR:** بيفتح بحث خرائط جوجل على القاعة — الرابط مكتوب في `tools/qr-url.txt`.
  لو عايز تغيّره لموقع مظبوط بإحداثيات، ولّد QR جديد وبدّل الـ `<svg>` اللي جوّه `<div class="qr">` في `index.html`.

## إعادة توليد الرسومات (اختياري)

```bash
pip install segno                    # للـ QR بس
python3 tools/gen_art.py    tools/couple.svg
python3 tools/gen_corner.py tools/corner.svg
python3 tools/build.py tools/couple.svg tools/corner.svg tools/qr.svg index.html
```
