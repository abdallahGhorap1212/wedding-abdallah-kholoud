# دعوة زفاف عبدالله وخلود 🤍

موقع دعوة زفاف — HTML/CSS/JS بس، من غير أي build أو مكتبات، يشتغل على GitHub Pages على طول.

**التفاصيل:** السبت ١٠ أكتوبر ٢٠٢٦ — من ٣ عصرًا حتى ٧ مساءً — قاعة سندريلا، قصر الأميرات، حديقة العاشر من رمضان، مدينة نصر.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | كل محتوى الدعوة + رسمة العريس والعروسة (SVG) |
| `styles.css` | التصميم والألوان |
| `script.js` | العد التنازلي، إضافة الموعد للتقويم، المشاركة |
| `images/couple.jpg` | صورتكم (اختياري — انظر تحت) |

## تحطّ صورتكم الحقيقية إزاي

حطّ الصورة باسم **`images/couple.jpg`** بالظبط. الموقع هيلاقيها لوحده ويحطها مكان الرسمة.
لو مش لاقيها بيرجع للرسمة تلقائيًا — يعني مفيش حاجة هتتكسر.

- يُفضّل صورة **مربعة** (مثلًا 800×800) لأنها بتتعرض داخل إطار دائري.
- خلي الوشوش في نص الصورة عشان القص الدائري ما ياكلش حاجة.

## الرفع على GitHub Pages

```bash
cd wedding-abdallah-kholoud
git remote add origin https://github.com/<اسم-حسابك>/<اسم-الريبو>.git
git branch -M main
git push -u origin main
```

بعدين من صفحة الريبو على GitHub:

**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**

استنى دقيقة والرابط هيبقى:
`https://<اسم-حسابك>.github.io/<اسم-الريبو>/`

## تعديلات سريعة

- **الأسماء / التاريخ / المكان:** كلها نص عادي جوه `index.html`.
- **موعد العد التنازلي:** أول سطرين في `script.js` — `new Date(2026, 9, 10, 15, 0, 0)`
  (خد بالك: الشهر بيبدأ من صفر، يعني `9` = أكتوبر).
- **الألوان:** في أول `styles.css` جوه `:root`.
